# Scarecrow Mod for Factorio 2.0+

A simple wooden box with an equipment grid - because sometimes you need to put equipment somewhere that isn't your armor.

## Features

- **Equipment Grid Storage**: 4x4 equipment grid accepting armor-category equipment (scales with quality up to 13x13)
- **Stationary Container**: 16 inventory slots (same as wooden chest)
- **Acts as decoy**: Considered military target. Why not fool biters, huh?

## Credits

Created as a simple utility mod to enable stationary equipment grid storage in Factorio 2.0.
